# Welcome to the demo

This folder exists to check how Quill looks and feels after every change. Open it with `Ctrl+O`, then walk through the notes below and compare against what you remember.

- [Typography](Typography.md): headings, long justified paragraphs, lists, quotes, code and tables.
- [Mathematics](Mathematics.md): inline and display math, aligned equations, matrices and an error.
- [Diagrams and embeds](Diagrams%20and%20embeds.md): Mermaid, an image, and an animated embed.
- [A nested note](lectures/A%20nested%20note.md): a note inside a subfolder, with an image linked upwards.

Things to try on each note:

1. Switch to writing with `Ctrl+E`, edit something, and switch back.
2. Paste a screenshot while writing.
3. Toggle the note list with `Ctrl+\` and focus mode with `Ctrl+Shift+F`.
4. Change the system theme between light and dark.

If you edit these notes while testing, discard the changes with `git checkout demo/` afterwards.
